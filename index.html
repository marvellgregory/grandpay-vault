Built on Arc

Why Arc?

Arc is Circle's open Layer-1 blockchain, purpose-built for programmable money and stablecoin-native finance.

⚡

Sub-Second Finality

Arc delivers deterministic finality in under 1 second. Your gift settles before the moment passes.

💵

USDC for Gas

No volatile native token for fees. Arc uses USDC, so you always know what you are paying.

🔗

EVM Compatible

Full Solidity support. Deploy with Remix, Hardhat, or Foundry. Standard tooling, new infrastructure.

🌐

Circle Integration

Integrated with Circle's full-stack platform including USDC, CCTP, Gateway, and developer services. See arc.io.

Trust & Security

Transparency, not hype.

We only claim what we can demonstrate. Here is what is actually true about GrandPay Vault.

🔐

Non-Custodial

GrandPay Vault never holds your funds. USDC is locked in a smart contract. Only the designated recipient can withdraw after the unlock date.

🔓

Open Source

All smart contract code is publicly available on GitHub. Review, audit, and verify the implementation yourself.

⚠️

Testnet Project

GrandPay Vault is currently deployed on Arc Testnet. This is not a production application. Do not use real funds.

🧾

Not Audited

The smart contracts have not been formally audited by a third-party security firm. Use at your own risk during the testnet phase.

FAQ

Questions and Answers

GrandPay Vault lets you create time-locked USDC vaults as programmable gifts. Lock USDC with a personal message, set an unlock date, and share the gift. The recipient can claim the funds after the unlock date. Built on Arc, Circle's Layer-1 blockchain.

Arc is Circle's open Layer-1 blockchain designed for programmable money. It offers sub-second finality and uses USDC for gas fees. Arc is currently in public testnet. See arc.io for the latest on mainnet timing and ecosystem partners.

GrandPay Vault is currently deployed on Arc Testnet. This is a testnet application, not a production product. Do not send real funds. A mainnet deployment is planned when Arc mainnet launches.

MetaMask is the primary supported wallet. Any Web3 wallet that supports custom EVM chains can be used. You will need to add Arc Testnet to your wallet manually or it will be added automatically when you connect.

No. GrandPay Vault is non-custodial. Your USDC is locked in a smart contract onchain. Only the designated recipient can withdraw after the unlock date. The platform never takes custody of your funds.

Arc Testnet (primary), Ethereum, Base, Polygon, Arbitrum, and Optimism. Smart contracts are currently deployed only on Arc Testnet. Other chains are planned for future deployment.

Yes. The smart contract code and frontend are publicly available on GitHub. You can review, fork, and verify the implementation.

GrandPay Vault does not charge platform fees during the testnet phase. You will pay standard Arc Testnet gas fees (in USDC) when creating vaults or splitting bills. Get testnet USDC from the Arc faucet.

Once a vault is created onchain, it cannot be cancelled or modified. The USDC is locked until the unlock date. Make sure you have entered the correct recipient address and amount before confirming the transaction.
